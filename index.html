01

BioAgent-ST ↗

FEATURED / SCIENTIFIC AGENTS

Scientific analysis.
With an evidence trail.

A verification-first agent for spatial transcriptomics. The model plans the work; deterministic tools run the science. Every claim stays attached to its evidence.

Co-created with Sourav Sarkar

Python · Scanpy · FastAPI · Next.js · SQLite

Explore source ↗

Built with Sourav Sarkar. Typed workflow plans separate the language model from scientific calculations. Policy gates validate execution; a SQLite ledger and SHA-256 hashes preserve the evidence trail. The repository documents 154 unit tests.

Explore the architecture & reproduction steps ↗
02

WineLens ↗

DATA SCIENCE

From chemical measurements to wine-quality estimates. Exploratory analysis, model comparisons, and a closer look at prediction errors.

scikit-learn · pandas · Random forests · Streamlit

Source ↗

Compares regression and classification on the UCI wine-quality data, with an interactive Streamlit app for 11 chemical measurements. The tuned random forest reports an exploratory MAE of 0.414. Repeated use of the test split means the result is not an independent estimate of generalisation.

Read the experiments & limitations ↗
03

TruthScope ↗

RAG & EVALUATION

An evidence-first RAG explorer that breaks answers into claims, checks their support, and makes the source evidence visible.

Python · Retrieval · Claim verification · Streamlit

Source ↗

A student exploration of answer verification, with a claim inspector, evidence viewer, and side-by-side system comparison. The committed benchmark uses a deterministic local simulator; it demonstrates the pipeline rather than establishing real-world LLM performance. Claim support is checked heuristically against the indexed corpus.

Read the methods & limitations ↗
04

TokenLab ↗

DEVELOPER TOOLS

A small lab for seeing how language models read text. Inspect tokens, decode IDs, and compare estimated API costs, all in the browser.

JavaScript · Byte-pair encoding · tiktoken parity

Source ↗Live demo ↗

Implements byte-level BPE for four OpenAI encodings, checked against tiktoken on 20 cases. Other model families are explicitly labelled as approximations. The 61-model pricing table is a September 2026 snapshot. No backend or API keys required.

Read the implementation notes ↗
05

VARUNA ↗

COMPUTER VISION

Maritime intelligence from satellite radar: oil-spill detection, visual explanations, ocean-drift reconstruction, and vessel-trajectory analysis.

Python · CNN · Sentinel-1 SAR · Grad-CAM

Source ↗Live demo ↗

Built with Team CODE_FORUN for Smart India Hackathon 2026. A compact CNN classifies Sentinel-1 SAR scenes, with Grad-CAM to inspect the regions behind a prediction. The broader platform brings together slick segmentation, drift hindcasting, and AIS trajectory correlation in a geographic interface.
