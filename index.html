TruthScope

rag · evaluation · 2026

An evidence-first way to see where RAG systems hallucinate.

A 60-question benchmark across 51 space-mission documents comparing baseline, loose Top-3 and strict Top-3 retrieval. Every answer is split into claims and checked against the retrieved evidence, so failures are visible instead of hidden behind one score: hallucination falls 93.3% → 6.7% and token F1 rises 0.22 → 0.85.

TokenLab

llm tooling · 2026

A tokenizer, converter and API cost lab in a single page.

Live token splitting across four exact OpenAI encodings, a token-ID decoder, a both-way words ⇄ tokens converter, and a cost calculator over a price table of 61 real models. The byte-level BPE engine is verified bit-identical to tiktoken on 20 test cases — no framework, no build step, no backend.
